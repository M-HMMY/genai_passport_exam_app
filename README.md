# 生成AIパスポート 学習アプリ

生成AIパスポート試験（GUGA＝一般社団法人生成AI活用普及協会）の学習アプリです。**教本（通読できる読み物）を軸に**、確認問題、間隔反復による復習、直前チェックシート、模試、成績分析までを 1 つにまとめます。学習記録はブラウザの localStorage にのみ保存され、**外部には一切送信されません。**

同じ作りの資格学習アプリを 4 つ作ってきた土台の上に乗っています。画面の作り・記法・運用の作法はそれらと共通です。

> **現状** アプリの仕組みは動きますが、**教本と問題の中身はこれから書きます。**章立て（12 章）と節割り（41 節）は確定済みです。書き方は [CLAUDE.md](CLAUDE.md) を参照してください。

## 想定する読者

この試験には受験資格がなく、合格率は 8 割前後。受けるのは **AI を業務で使い始めた社会人、営業・企画・人事などの非技術職、学生**です。

- **数式は出しません。**シラバスの詳細キーワードに、数式を要求する項目は 1 つもありません
- **そのかわり英略語が大量に出ます**（AGI・ANI・RLHF・NLP・LLM・RAG・MCP・MLM・NSP・VAE・GAN・RNN・LSTM・CNN）。初出で「正式名称・訳・何をするものか」の 3 点セットを書きます
- 仕組みは図と例え話で説明します

## この試験の特徴

| 項目 | 内容 |
| --- | --- |
| 形式 | **四肢択一式（一部複数選択を含む）**。記述も実技もない |
| 問題数・時間 | **60 問を 60 分**（1 問あたりちょうど 60 秒） |
| 実施 | **オンライン（IBT）年 5 回**（2・4・6・8・10 月）。各回とも受験期間が 1 か月ある |
| 受験資格 | なし |
| 受験料 | 一般 11,000 円 / 学生 5,500 円（税込） |
| 合格基準 | **非公表** |
| 合格率 | **79.90 %**（2026 年 6 月試験） |
| 資格の有効期限 | なし。ただしシラバス改訂時に**資格更新テスト**が別途ある |
| シラバス | 2026 年 2 月試験より適用の版。書き起こしが [docs/syllabus-2026-02.md](docs/syllabus-2026-02.md) にあります |

**合格基準が非公表なので、このアプリは合否を判定しません。**合格率が高いこともあって「7 割」「8 割」といった目安が出回っていますが、いずれも非公式です。模試の結果画面が出すのは、正答率・**時間内に解き切れたか**・分野別と章別の正答率の 3 つだけで、点数への換算も「合格圏」といった表示もしません。模試の構成比はシラバスのキーワード数から按分した推定値で、**本番の内訳ではありません**（GUGA は公表していません）。

**本番には一部、複数選択の問題が含まれます。**このアプリの確認問題と模試は、いまのところ四肢択一だけです。

要項もシラバスも改訂されます。申し込みの前に [GUGA の公式サイト](https://guga.or.jp/outline/) で最新の情報を確認してください。

## 起動

```
npm install     # 初回のみ
npm run dev     # http://localhost:5173 が開く（開発用・自動リロードあり）
npm run build   # 本番ビルド（出力は dist/）
npm run preview # http://localhost:4173 でビルド済みのものを配信
npm run check   # データの整合性チェック（教本・問題・描画）
```

`scripts/launch.cmd` をダブルクリックしても起動できます（ビルド済みのものを配信します）。

アイコンは `python scripts/make_icons.py` で作り直せます（外部ライブラリ不要）。PWA 用の `public/icons/` とショートカット用の `scripts/app.ico` の両方を書き出します。

## iPhone / Android で使う

PWA なので、**ホーム画面に追加するとアドレスバーのないアプリとして起動**し、一度開いたページはオフラインでも読めます。

**iPhone（Safari で開くこと。Chrome や他のブラウザからは追加できません）**

1. 公開 URL を **Safari** で開く
2. 画面下部の共有ボタン（□に↑）をタップ
3. メニューを下へたどって「**ホーム画面に追加**」

**Android** … Chrome のメニューから「アプリをインストール」または「ホーム画面に追加」。

### 知っておくとよいこと

- **オフライン保存（Service Worker）は HTTPS でのみ有効です。**同じ Wi-Fi 内で `http://192.168.x.x:5173` を開く方法でも閲覧はできますが、オフライン保存は効かず、PC 側でサーバを動かしておく必要があります
- **学習記録は端末ごとです。** PC とスマートフォンでは共有されません。設定画面のエクスポート／インポートで移せます
- ホーム画面のアイコンを削除すると、その端末の学習記録も消えます

## GitHub Pages へ公開する

[.github/workflows/deploy.yml](.github/workflows/deploy.yml) を用意してあります。**`main` ブランチへ push するたびに**自動でビルドして公開されます。

初回だけ次の手順が必要です。

```powershell
git remote add origin https://github.com/<ユーザ名>/<リポジトリ名>.git
git push -u origin main
```

その後、GitHub のリポジトリで **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に変更します。数分後に `https://<ユーザ名>.github.io/<リポジトリ名>/` で公開されます。

`vite.config.ts` の `base` は `'./'`（相対パス）で、ルータもハッシュ方式なので、**リポジトリ名がどうであってもサブディレクトリ配信で正しく動きます。**

公開リポジトリにするので、**コミットの署名には GitHub の noreply アドレスを使ってください**（実メールアドレスは履歴に永久に残ります）。

## 画面

| 画面 | 内容 |
| --- | --- |
| ホーム | 進捗、試験日カウントダウン、1 日のノルマ、弱点分野、「もう一度読みたい節」 |
| 教本 | 章順に読む本編（12 章 41 節）。全文検索・栞・理解度 3 段階の記録つき |
| 体験ツール | 対話ウィジェットの一覧（`src/components/widgets/` にファイルを置くと自動で有効になる） |
| 確認問題 | 四肢択一。章別／出題数指定／誤答優先。1 問ごとに解説と教本への導線 |
| 直前チェック | 全節の「まとめ」「試験のポイント」「よくある勘違い」を抜き出した一覧 |
| 復習 | SM-2 を簡略化した間隔反復。誤答は自動的にここへ回る |
| 模試 | 本番と同じ問題数・時間制限つきの通し演習。**合否は判定しない**（上記） |
| 成績分析 | 分野別の正答率、日別の推移、模試の履歴 |
| 設定 | 試験日、テーマ、学習記録のエクスポート／インポート |

## 技術的な前提

- React 18 + Vite 5 + TypeScript（strict、未使用変数もエラー）
- **ランタイム依存は React だけ。** ルータも Markdown も図も自前で、**外部通信は一切しない**
- 学習記録は localStorage のみ。サーバもアカウントもない
- Service Worker によるオフライン対応（HTTPS でのみ有効）

**第 5 章がプロンプトの章ですが、生成 AI の API を叩く機能は作りません。**プロンプトの例は読んで覚えるためのものです。

## 内容の正しさについて

このアプリの教本と問題は生成 AI で書きます。**書いた本人が読み返しても誤りは見つからない**ことが系譜を通じて分かっているため、**別の目で通しレビューする工程**を必ず入れます（姉妹アプリでは、自己レビューでの発見 0 件に対し、別の目で 200 件超の指摘が出ました）。

それでも誤りは残り得ます。**特に法律・ガイドラインの年数と条番号、生成 AI 分野の「いま」の記述**は、一次資料で確かめてください。教本の中でも「いつ時点の話か」を書くようにしています。
