**節 ID はここで確定させます。**あとから変えると次がいっせいに壊れます。

- 確認問題の `sectionId`
- 本文中の `[文字](textbook/節id)` リンク
- `src/data/categories.ts` の `GLOSSARY_SECTION_ID`（`i-4`）と `MATH_SECTION_ID`（`i-3`）

**増やすときは章の末尾に足してください。**間に割り込ませると番号がずれます。

「分」は目安の学習時間で、`TextbookSection.minutes` に入れる値のあたりです。
